## 0. 한 줄 요약

이완된 모아레에서 결함의 **먼 렌즈 질량**은 원자 수준 값 m = C/κ보다 작아집니다(m_eff = ρ·m). 이 비율 ρ를 레지스트리 세기 V0와 강성비 K/μ의 함수로 정밀하게 잽니다. 함께 다음을 측정합니다.
- 해석 모형의 운동학적 관계 ρ ≈ θ/(θ + b): b는 코어 안쪽 원판의 과회전(twist) 또는 과팽창(mismatch)
- 에너지 모형에 필요한 **변형된 모아레의 에너지 밀도 e(G)**

상자 ±72에서는 맞춤에 쓸 노드가 13개뿐이라, 세 측정법 사이에 0.1–0.3의 차이가 납니다. **이번 의뢰의 첫째 목적은 큰 상자에서 이 차이를 없애는 것입니다.**

**해석 모형("과회전 원판 + 고정 고리").**
- 코어 둘레 반지름 r₁의 원판은 배경보다 b만큼 더 회전(twist)하거나 더 팽창(mismatch)합니다.
- 그 바깥 고리에서 레지스트리는 AB로 고정됩니다.
- 먼 모아레는 안쪽 원판의 국소 κ_in = κ + b(twist에서는 i(θ+b))로 결함을 봅니다.

이로부터 다음이 나옵니다.

  m_eff = C/κ_in,  ρ = θ/(θ+b),  r₁² = |C|/(θ+b) (안쪽 원판의 아인슈타인 반지름)

에너지는 다음과 같이 씁니다.

  E(ρ)/(2π|C|) = A(1−ρ)²/ρ + Γ(ln ρ + 1 − ρ)

- A = μθ (twist; 안쪽 회전은 공짜) 또는 (μ+K)θ (mismatch; 안쪽 팽창에 K 비용)
- Γ는 벽 장력(모아레 에너지 밀도/국소 기울기)

이 에너지를 최소화하면 ρ = A/(Γ − A)이고, Γ ≤ 2A이면 ρ = 1(가림 없음)입니다. 두 항이 모두 |C|에 비례하므로 ρ는 |C|와 무관하고, 이는 P1과 일치합니다.

Γ는 아직 정량화하지 못했습니다. 근접 영역은 회전보다 국소 전단(heterostrain)이 지배하므로, **전단된 모아레의 에너지 밀도 e(G)**가 필요합니다(S0). twist에서 K가 클수록 더 가리는 현상은 이 e(G)의 K 의존(혼합형 벽의 인장 성분)으로 설명될 것으로 예상합니다.

## 2. S0 (필수, 가장 먼저): 변형된 모아레의 에너지 밀도 e(G)

주기 셀 코드(`pair/permod2*.py`, 모아레 탄성상수를 잰 코드)를 써서, 균일한 변위 기울기
  ∇u = G = θ·[회전 R(α)] + η·[전단]
을 갖는 **주기 모아레**를 이완하고 단위 면적당 에너지 e(G)를 잽니다. 주기 셀은 G에 맞는 모아레 격자를 써야 합니다.

- 매개변수:
  - 배경: twist(α=90°), mismatch(α=0°)
  - |η/θ| ∈ {0, 0.25, 0.5, 1, 1.5, 2, 3, 5}
  - 전단 방향 arg η ∈ {0°, 30°}
  - V0 ∈ {0.0025, 0.005, 0.01, 0.02}
  - K/μ ∈ {0.1, 0.5, 2}(λ = −0.9, −0.5, 1)
- |η/θ| = 1에서는 det G = 0이 되어 모아레 주기가 발산합니다. 이 점은 빼고 0.9, 1.1로 대신합니다.
- |η/θ| > 1이면 det < 0, 즉 뒤집힌 모아레입니다. 이것이 근접 영역의 실제 상태입니다.
- 출력은 `pair/eG.json`입니다(배경, λ, V0, η, arg η, e, e_unrelaxed, 맞춤 정보).
- 그림 `pair/eG.png`: e/(μθ²)를 |det G|^{1/2}/θ 또는 (σ₁+σ₂)/2θ에 대해 그리고, 벽 장력 근사 e ≈ Γ(σ₁+σ₂)와 비교합니다. σ는 G의 특이값입니다.
- 목적: 에너지 모형의 이득 항 G(ρ) = ∫_{r₁}^{R}[e(근접장) − e(배경)]2πr dr을 피팅 없이 계산하는 것입니다. 이득 항의 계산은 의뢰자 쪽에서 합니다.

## 3. S1 (필수): 큰 상자에서 ρ(V0, K/μ) 격자 스캔

- 상자 ±150(노드 약 90개)을 씁니다. 결함은 |C| = 8, 위치 GEN, φ_m = 0입니다.
- V0 ∈ {0, 0.00125, 0.0025, 0.005, 0.01, 0.02}입니다. V0=0은 순수 탄성 기준이고 배경은 해석적 u_b입니다.
- K/μ ∈ {0.1, 0.5, 1, 2}(λ = −0.9, −0.5, 0, 1)입니다.
- 배경은 twist와 mismatch 두 가지입니다.
- 초기값은 (a) 선형 렌즈장과 (b) 이완된 배경 두 가지이고, 에너지가 낮은 쪽을 주 결과로 하되 둘 다 기록합니다.
- 합계: 6 × 4 × 2 × 2 = 96개 실행 + 배경 48개입니다. 배경은 결함과 같은 격자를 써야 합니다.

**측정 (각 실행):**
1. **ρ_node**: `screen/mfit.py` 방식입니다. 노드 꼬리표를 추적해 변위를 Δz = m_eff/conj(w) + b₀ + b₁w + b₂ conj(w)로 맞춥니다(w = 배경 노드 위치 − z₀). 맞춤 구간은 1.5R+5 < |w| < L_p − 8입니다. 셸 세 구간으로 나누어 반지름 의존성도 기록합니다.
2. **ρ_int, ρ_area**: `screen/ana.py`(창 [1.5R+10, L_p−15])입니다.
3. **안쪽 과회전·과팽창 b**: `screen/prof.py`처럼 배경을 뺀 δω와 δdiv의 방위각 평균 프로파일을 r ∈ [r_h+1, 2R]에서 2 간격으로 저장합니다. b̄는 r ∈ [r_h+1, 0.6R]의 r 가중 평균이고, mismatch에서는 b = δdiv/2를 씁니다.
4. **고정 고리**: 각 고리에서 V < 0.1·V0인 면적 비율을 배경과 비교합니다.
5. **토크·힘쌍극자 프로파일**: `screen/torque.py`로 원을 지나는 토크 τ(r)와 반지름 견인 적분 P(r)를 구합니다. 배경을 빼고 r ≤ 3R 구간을 기록합니다.
6. E − E_bg, 반복 수.

**출력:** `pair/screen_scan.json`과 그림 `pair/screen_scan.png`입니다. 그림은 세 패널로 구성합니다.
- (a) ρ_node 대 V0/(μθ²), K/μ별 선, 두 배경
- (b) ρ_node 대 θ/(θ + b̄), 대각선 포함
- (c) τ(r)/τ₀ 프로파일 예시

## 4. S2: |C|와 위치 의존성 확인

- K/μ ∈ {0.5, 2}, V0 ∈ {0.0025, 0.005, 0.02}, 두 배경입니다.
- |C| ∈ {4, 16}: 상자 ±150에서 같은 측정을 합니다. ρ가 |C|와 무관한지(모형의 예측) 확인합니다.
- 위치 AA, AB, SP(|C| = 8): 위치에 따른 차이를 봅니다.
- 합계는 약 2 × 3 × 2 × (2 + 3) = 60개입니다.

## 5. S3: φ_m 의존성

- |C| = 8, GEN, K/μ ∈ {0.5, 2}, V0 ∈ {0.005, 0.02}, 두 배경입니다.
- φ_m ∈ {180°, 90°}를 계산합니다.
  - φ_m = 180°: 음의 질량입니다. 모형에서는 안쪽이 덜 회전(b < 0)해야 합니다. 이 부호를 확인합니다.
  - φ_m = 90°: m_eff가 복소수가 되어 크기와 방향이 함께 바뀌는지 봅니다. 노드 맞춤에서 m_eff/m의 복소 비를 기록합니다.
- 합계는 2 × 2 × 2 × 2 = 16개입니다(초기값 a, b 모두면 32개).

## 6. S4: 상자 크기 수렴

- 고정 경계가 만드는 b₁(z), b₂(z̄) 항이 상자 크기에 반비례하는지도 기록합니다.
