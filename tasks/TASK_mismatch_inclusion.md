# 계산 의뢰서: mismatch 모아레 고유팽창 원판 검증 (f_α 직접 측정)

> 대상: Claude Code(또는 사람). 저장소 `moire-iris-lens` 루트에서 실행.
> 예상 계산량: 필수 묶음(P1, 작업 12개) 약 20–30 CPU-시간, 전체 약 50–70 CPU-시간. 코어 수만큼 나누어 병렬로 돌릴 수 있음.

## 0. 한 줄 요약

모아레 격자 안의 원판(반지름 r₀)에 **모아레 고유팽창 ε\***을 넣고, 바깥 모아레 노드가 얼마나 밀리는지 정확히 잽니다. 그 값으로 응답 계수 S를 구하고, 주기 셀에서 잰 탄성상수가 주는 선형 예측 **S = K_M/(K_M+μ_M) = 0.363**과 비교합니다.

## 1. 배경: 지금까지 확정된 것

모형: 상대 변위 u(레지스트리)에 대한 등방 탄성(μ=1, λ=−0.5)과 육방 레지스트리 퍼텐셜 V(u)를 씁니다. V는 `hex/hexcore.py`의 `Vhex`이고 V0=0.005, V3=√3V0입니다.
- 배경: u_b = c₁ + κz, θ = 1/30, κ = θe^{iα}. twist는 α=90°, mismatch는 α=0°입니다.
- 모아레 변위 U는 u = κ(z − U)로 정의합니다.
- 상수: A_c = √3/2, A_M = A_c/θ² ≈ 779, 모아레 주기 L_M = 30.

**주기 셀에서 잰 모아레 탄성상수** (θ² 단위; `pair/permod2*.py`, 결과 파일 `pair/permod2_fit.json`):

| | K_M | μ_M | χ_M (회전) | σ_d (1차 항) | S = K_M/(K_M+μ_M) |
|---|---|---|---|---|---|
| twist | −0.149 | 1.149 | +6.41 | −3.34 | −0.149 |
| **mismatch** | **0.273** | **0.479** | **−1.29** | −5.92 | **0.363** |

**선형 이론.** 원판 안 고유팽창이 ε\*이면 삽입 면적은 δA\* = 2πr₀²ε\*입니다. 바깥 해는 U_r = A/r + Br이고 A = S·ε\*r₀²입니다.
- A는 바깥 경계 조건과 무관합니다.
- 교차항이 0이므로 χ_M은 S에 들어가지 않습니다.
- 경계가 고정이면 B = −A/L²입니다.
- 원판 안의 균일 변형률은 S·ε\* − A/L²입니다.

**twist에서 이미 확인된 사실** (`pair/moire_moduli.png`, `pair/ringfit.json`, 2026-10-31 수정):
- 결함이 없어도 고정 상자 안의 벌크 모아레는 균일하게 팽창해 있고, 팽창량은 상자 크기에 반비례합니다(ε₀ ≈ 2.7/L). 남는 비틀림은 가장자리 층이 떠안습니다.
- 그러나 **가장자리는 단단합니다.** 경계에 팽창 η를 걸면 벌크가 거의 1:1로 따라가고(dε_b/dη = 1.16(상자 ±54), 0.87(±72)), 원판 바깥 장은 고정 경계 모양 A(1/r − r/L_eff²)를 따릅니다(L_eff ≈ 155–160).
- 앞서 r₀=60에서 보인 거대 응답(S_eff = −5 ~ −8, 진폭 의존)은 **원판 경계가 반지름 60의 노드 껍질을 정확히 지나가서 생긴 인공물**이었습니다. "호흡 모드" 해석은 철회합니다.
- 경계를 노드 껍질 사이에 두면 응답이 정상 범위로 돌아옵니다. r₀=70에서는 S_fit = −0.78, −0.81(±ε 대칭, 선형). r₀=45에서는 −0.46, ~0(비대칭).
- 남은 문제: 부호는 벌크 예측(−0.149)과 같지만 크기가 3–5배이고, 경계가 모아레 무늬의 어디를 지나느냐에 따라 값이 달라집니다(r₀ ≈ 1.5–2.3 L_M의 이산성).
- **모아레 노드 껍질 반지름**(twist와 mismatch 공통)은 30·{1, √3, 2, √7, 3, 2√3, √13, 4, …} = 30, 52, 60, 79, 90, 104, 108, 120, …입니다. r₀는 이 값들에서 멀리 둡니다.

**mismatch는 K_M>0이므로 선형 예측이 맞을 것으로 기대합니다. 이번 의뢰는 그 기대를 검증하는 것입니다.** 한 가지 주의할 점은 χ_M<0(자발 회전 경향)이라는 것입니다. 그래서 회전 성분 ΔU_t도 함께 봅니다.

## 2. 무엇을 계산하나

### 원판 구현 (이미 구현됨: `pair/pair4.py`의 `incl=(x0,y0,r0,eps)`)
원판 안 |z|<r₀에서 에너지를 u 대신 u + s에 대해 계산합니다. 여기서 s = κε\*(z − z₀)입니다.
- 탄성 기울기에 κε\*를 더합니다.
- V는 V(u + s)로 계산합니다.
- 원판 안의 "자연 상태"는 모아레가 ε\*만큼 팽창한 상태입니다. 원판 경계에서 s가 불연속인데, 이것이 모아레 전위가 고리처럼 분포한 것에 해당합니다(이 불연속 없이는 고유변형이 생기지 않습니다).
- 바깥 경계는 2줄을 u_b로 고정합니다. 격자 간격은 h = 0.45입니다.

### 측정 (이미 구현됨: `pair/nodedisp.py`, `pair/incl_analyze.py`)
1. 모아레 노드 위치는 u(z) = c₁ + (격자 벡터)를 Newton법으로 푼 해이고, 정밀도는 ~1e-14입니다. 각 노드의 반지름 방향 변위 U_r을 잽니다.
2. ε\*=0 기준 상태를 빼서 ΔU_r = U_r(ε\*) − U_r(0)을 구합니다.
3. 정규화에는 **이완 없는 mismatch(V0=0)**를 씁니다. 이 경우 S = 1/3이 정확하고, 반지름 의존성(고정 경계 효과)도 해석적으로 알려져 있습니다. 같은 노드 껍질(shell)에서 비를 취하면 모양 함수가 약분됩니다.
   S_shell(r) = (1/3)·[ΔU_r(r)/ε\*] / [U_r^bare(r)/ε_bare]
4. 출력은 S_inside(r < r₀−5 껍질 평균)와 S_outside(r > r₀+10 껍질 평균)입니다.

## 4. 실행 방법

```bash
cd pair
python incl_scan.py ../tasks/jobs_P1.txt  <동시작업수>
```

- `incl_scan.py`는 각 작업을 `incl_ck.py`로 실행합니다. 400 반복마다 `<tag>_ck.npz`에 체크포인트를 저장합니다.
- **중간에 끊기면 같은 명령을 다시 실행하면 됩니다.** 끝난 작업은 건너뛰고, 진행 중이던 작업은 이어서 돕니다.

### 판정: 5절 표의 2행(r₀ 의존, 경계 이산성) + 4행(ΔU_t/ε ≠ 0). 1행(S ≈ 0.36, 선형 연속체)은 성립하지 않음

- **r₀ 의존성이 큽니다.** r₀=45: S_fit = +0.63/+1.10(부호는 예측과 같지만 크기 2–3배, ±ε 비대칭). r₀=70의 작은 진폭 가지: −0.26 ~ −0.70(부호 반대). r₀=60(노드 껍질 위): −5.5/−7.5. 같은 물질 상수(S = 0.363)로 묶이지 않으므로 twist와 같은 **경계 이산성** 상황입니다. 후속은 P2(r₀=95)입니다.
- **r₀=60만 벗어나는 것은 아닙니다(3행 아님).** r₀=70에서도 ε\*=−0.01(+5.5), −0.02(−7.0)가 같은 r₀의 다른 진폭과 크게 다릅니다. ε\*=−0.01 작업은 계산 도중 에너지가 한 번 크게 떨어졌습니다(7600–11200회 사이, 552.152 → 552.072). **음의 ε\*에서 다른 준안정 상태로 넘어가는 것**으로 보입니다. r₀=70의 +ε 쪽과 −0.005는 서로 연속적이며(S_fit −0.26 ~ −0.70), ε\*가 커질수록 |S_fit|이 줄어듭니다.

## 의뢰자 해석 (2026-11-01): 원판은 모아레 고유팽창이 아니라 "고리 견인력"으로 작용한다

### 정확한 항등식
기준 상태 u₀(ε\*=0의 평형)에서 포락선 정리를 쓰면, 원판 에너지의 1차 계수는
E₁ ≡ ∂E/∂ε\*|₀ = ∫_D σ_at : G_κ dA + ∫_D ∇V(u₀)·κ(z−z₀) dA
입니다. 여기서 σ_at는 원자 코시 응력이고, G_κ는 z ↦ κz의 기울기 행렬입니다. 기준 상태의 평형 조건 ∇V = div σ_at를 넣어 부분적분하면 부피 항이 정확히 상쇄되고
**E₁ = ∮_{∂D} (σ_at n)·κ(z−z₀) dl**
만 남습니다. 즉 원판은 고리 위의 미시 견인력에만 결합합니다.
- **twist**(κ = iθ): κ(z−z₀)는 고리의 접선 방향입니다. 따라서 E₁ = θr₀∮t_t dl, 곧 고리에 걸리는 미시 토크입니다.
  - 원판 중심 위치를 모아레 셀 안에서 바꿔 평균하면 ⟨σ_at⟩가 대칭이므로 **평균은 0**입니다.
  - 연속체 모아레 예측(−πr₀²σ_d, σ_d = −3.34θ²)은 r₀=70에서 +57이지만, 이 결합은 나타나지 않습니다.
- **mismatch**(κ = θ): κ(z−z₀)는 반지름 방향입니다. 따라서 E₁ = θr₀∮t_n dl이고, 위치 평균은 θ·πr₀²·tr⟨σ_at⟩ = **2θ²πr₀²**입니다(평균 원자 응력은 θ, tr = 2θ).
  - 이 평균은 r₀ = 45, 60, 70, 95에서 각각 14.1, 25.1, 34.2, 63입니다.
  - 모아레 구성 응력 σ_d = −5.92θ²가 주는 −πr₀²σ_d(r₀=70에서 101)와 다릅니다.
- 위치에 따른 요동은 고리 길이에 비례합니다(∝ r₀). r₀가 L_M의 몇 배 정도인 범위에서는 이 요동이 평균과 같은 크기입니다.

### 결론
1. 레지스트리를 옮겨 만든 원판은 **동질화된 모아레 고유팽창이 아닙니다.** 원판은 원자 응력에 결합하고, 모아레 구성 응력(σ_d, 주기 셀의 1차 계수)에는 결합하지 않습니다. 그래서 S = K_M/(K_M+μ_M)가 나올 이유가 없고, r₀·위치·부호에 따라 값이 흩어지는 것은 고리 미시 견인력의 요동 때문입니다.
   - ε\* 부호에 따른 준안정 상태 전이도 같은 맥락입니다. 견인력이 고리 근처에 몰려 있어 그 근처 노드가 재배열(도약)합니다.
2. 같은 논리가 실제 모아레 전위 쌍(기하학적 5-7 쌍)에도 적용됩니다. 전위 코어가 원자층에 주는 힘으로 결합하기 때문입니다. 그래서 **보편적인 f_α는 존재하지 않고**, 먼 전하는 다음 둘로 정확히 나뉩니다.
   - 정수 장부(노드 계산 항등식)
   - 코어 힘 쌍극자의 dressing(논문 4.5절 명제 8, C_reg = −TrP/[4π(λ+2μ)] − iM/(4πμ))
3. 주기 셀의 모아레 탄성상수(K_M, μ_M, χ_M)는 균일 변형에 대한 성질로서 유효합니다. 다만 국소 원천의 먼 장을 예측하려면 원천의 힘 쌍극자가 필요합니다.
